# Werkregels voor Codex

- Lees eerst alle relevante documenten en inspecteer de bestaande code.
- Gebruik een feature branch; werk niet rechtstreeks op main.
- Geen destructieve wijzigingen zonder toestemming.
- Geen secrets in commits, logs, screenshots of documentatie.
- Gebruik de bestaande package manager en lockfile; verander die alleen bewust.
- Controleer actuele officiële documentatie voor framework- en Cloudflare-configuratie.
- Installeer alleen dependencies die nodig zijn; leg doel en risico uit.
- Test iedere fase en geef concrete commando's/resultaten.
- Gebruik echte persistentie voor functies die als werkend worden gepresenteerd.
- Geen fake login, fake push, nep-synchronisatie of knoppen zonder werking.
- Privacy is een functionele eis: test dat gebruiker A geen privégegevens van gebruiker B kan lezen.
- Bevestig externe of potentieel onomkeerbare acties.
- Open een pull request naar main wanneer de eerste veilige oplevering gereed is; merge niet zonder toestemming.
- Eindrapport in begrijpelijk Nederlands: gewijzigd, getest, nog niet werkend, benodigde acties van Jesse.
